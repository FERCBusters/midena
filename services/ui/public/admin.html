API tokens

An API token lets another application, such as KEEN, list and open diagrams as one account: it sees exactly the diagrams that account can read, and it can change nothing. Issue each token for an account that holds only the access the other application needs.

The token is shown once. The account's holder is told by email when a token is issued or revoked for it. Deactivating the account revokes its tokens, and they stay revoked if it is activated again. Changing the account's password or second factors leaves its tokens as they are. Revoke a token as soon as the application that holds it no longer needs it.

API tokens are turned off for this installation. Set MIDENA_API_TOKENS_ENABLED=true to issue tokens and have MIDENA accept them. Tokens issued earlier are listed below and can still be revoked.
